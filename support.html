Help with Affelion Bible

Keep a copy of your writing

Open Settings → Export a private backup. Keep every exported file together somewhere private; they contain readable writing. Large journals use numbered parts. Before changing devices or uninstalling the app, check that you have a usable backup.

Restore a journal backup

Open Settings → Import an Affelion Bible backup and select all the numbered JSON parts from that backup together (or one older JSON backup up to 20 MB). Missing or mixed parts are rejected without changing your journal. Contact hello@affelion.com if an older backup is larger than this limit; do not send private prayer text by email. Valid entries are added; entries with the same identifier are kept rather than overwritten. The app does not provide automatic cloud sync.

Purchase support reference

Open Settings → Study library → Purchase support reference → Copy purchase reference. Paste it into an email to hello@affelion.com if you need purchase help. If automatic copying fails, select and copy the read-only reference. It contains no personal writing. If it says “Available after you open purchases”, open View library access or tap Restore purchases; Settings alone does not start billing. If it is still unavailable, tell us the error, platform and app version.

Restore course access

Use the same Apple or Google store account that purchased the course. Open Settings → Restore purchases. Apple purchases do not transfer to Google, or vice versa, in this version. Never buy the course again merely because a restore attempt failed; check your connection and store account first.

Request a refund

For an App Store purchase, follow Apple’s refund instructions. For Google Play, use Google’s refund instructions. The store decides eligibility. A refund request does not delete your writing.

Read aloud

The app uses your device’s speech service. If a voice is unavailable, check the device’s speech settings or continue reading on screen. Personal journal entries are not sent for narration.

Delete local writing

Delete an individual entry from its page, or use Settings → Erase app data from this device. Erase also cleans app-owned temporary export files and reports a cleanup failure honestly. It does not delete backups you saved elsewhere or remote purchase records.

Contact support

Email hello@affelion.com for support or privacy requests. Include your app version, device model and a description of the issue. Include the purchase reference for billing help. Never send journal, prayer or reflection text, a journal backup, full card details, a store password or a one-time code. Ask us to review a billing-data deletion request at the same email address; we verify the request before removing eligible records. Apple/Google retain their separate store records, and reopening or restoring can create a RevenueCat profile again. Deleting billing data does not refund a purchase.
